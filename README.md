# 🎵 Music & Mental Health 하이브리드 예측 모델링
> **비지도 학습(K-means) 기반 피처 엔지니어링을 통한 정신건강 유형 분류 고도화**

본 프로젝트는 음악 청취 습관과 정신건강 지표 간의 복잡한 관계를 분석하고, 단순 선형 모델의 한계를 하이브리드 모델링 기법으로 극복하여 예측 성능을 혁신적으로 개선한 사례입니다.

---

## 1. 프로젝트 개요
* **주제:** 정신건강 유형(Cluster) 예측 및 하이브리드 모델링 
* **데이터:** 736명의 설문 데이터 (33개 컬럼, 3-Class Imbalanced Data) 
* **역할:** 데이터 전처리, 가설 수립, 하이브리드 모델링 설계 및 성과 도출 (2인 리딩) 
* **핵심 성과:** 모델 정확도 **61% → 87% (26%p 향상)** 달성 

---

## 2. 분석의 한계와 관점의 전환 (Problem-Solving)

### 초기 모델링의 한계
* **낮은 상관관계:** 음악 청취 시간과 정신건강 지표 간 피어슨 상관계수가 0.1 미만으로 나타나 뚜렷한 선형 관계 부재 확인
* **분류 성능 정체:** 불안도를 3단계(상/중/하)로 분류하여 지도 학습을 시도했으나 정확도 61% 수준에서 정체

### 💡 관점의 전환: 하이브리드 모델링 도입 
* "선형적 관계가 없다면, 데이터 내부에 숨겨진 맥락(Context)을 군집으로 발굴하자"는 가설 수립
* 비지도 학습(K-means)을 전처리에 도입하여 새로운 파생 변수를 창출하는 전략 채택

---

## 3. 주요 분석 프로세스

### 01. 비지도 학습을 통한 맥락 발굴
* **K-means Clustering:** Elbow Method를 통해 최적의 군집 수 $k=3$ 도출 
* **군집 라벨링 (Feature Engineering):** 
    * **Cluster 0:** 정신건강 취약 그룹 
    * **Cluster 1:** 정신건강 양호 그룹 
    * **Cluster 2:** 특정 증상 취약 그룹 

### 02. 하이브리드 분류 모델 구축
* 도출된 군집 라벨을 새로운 독립변수로 추가하여 학습 진행 
* 단순 점수 예측에서 **'정신건강 유형 분류'**로 목표를 재정의하여 모델의 실용성 확보

---

## 4. 최종 결과 및 인사이트

### 정량적 성과
* **Accuracy:** 기존 61%에서 87%로 상승
* **한계:** 군집(Cluster)을 만들 때 사용한 심리 변수(Depression, Insomnia, OCD)가 이후 예측 변수에도 그대로 포함되어 있어, 이 정확도 상승분에는 데이터 누수(data leakage)의 영향이 일부 포함되어 있음 따라서 87%라는 수치를 "예측 성능의 순수한 개선"으로 해석하기보다는, 군집 자체가 유효하게 형성되었는지를 확인하는 결과로 보는 것이 더 정확함

### 정성적 인사이트
* 상관관계가 낮다고 해서 데이터에 구조가 없는 건 아니라는 걸 확인했고, K-means로 실제로 뚜렷한 하위 유형이 존재함을 발견
* 다만 이 하위 유형이 음악 습관 같은 독립적인 변수로도 재현되는지는 검증하지 못한 것이 이번 프로젝트의 한계이며, 향후 개선 방향으로 남겨둠
